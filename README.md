# BIO-Membrana

Landing responsive para la tienda de cosmética natural BIO-Membrana, hecha con HTML semántico, CSS propio y Bootstrap 5.3.8 local.

## Cómo verla

Abre `index.html` en el navegador o utiliza Live Server. No requiere compilación ni conexión a un CDN.

## Contenido

- `index.html`: portada con carrusel de imágenes claras, últimas novedades, sección de marca y fichas de producto en modal.
- `page/acerca-de.html`: historia, ingredientes, proceso y compromiso de la marca.
- `page/productos.html`: catálogo con seis productos y fichas en modal.
- `page/contacto.html`: formulario accesible con validación en el navegador y espacio adaptable para insertar el mapa cuando se confirme la dirección exacta.
- `dist/css/style.css`: estilos compartidos para la portada y las páginas internas.
- `dist/js/main.js`: interacciones de modales, aparición de tarjetas y validación del formulario.
- Menú flotante circular accesible con accesos a WhatsApp, X, Facebook e Instagram en todas las páginas.
- `dist/img/`: ilustraciones del carrusel y recursos de marca.
- `dist/productos/`: imágenes del catálogo.
- `dist/vendor/bootstrap/`: archivos locales de Bootstrap 5.3.8.

Las tarjetas y la portada tienen movimientos 3D sutiles; las preferencias de movimiento reducido del sistema se respetan.

El formulario de contacto es una demostración y todavía no envía datos a un servicio externo.

Los enlaces sociales abren las páginas generales de cada plataforma; reemplázalos por los perfiles oficiales de BIO-Membrana y agrega el número de WhatsApp para dirigir las consultas al negocio.
